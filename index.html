Conexão com o Projeto da Piscina

No projeto integrador, a piscina do CEP é aquecida de forma automatizada. Aqui investigamos como medir esse aquecimento: a física das medidas (Tecnociência) encontrando os sensores reais do protótipo (Robótica).

Questões orientadoras

Abra cada pergunta para ver um resumo

⚡ Como um sensor transforma uma grandeza física em sinal elétrico?

Pelo processo de transdução: no termistor, o calor muda a resistência elétrica; essa mudança vira variação de tensão que o Arduino lê pelo conversor analógico-digital. Ver simulação em Sensores →

📍 Como medir a temperatura em diferentes pontos?

Com vários sensores distribuídos (superfície, meio e fundo), porque a água estratifica: a parte de cima esquenta primeiro por convecção. Comparar os pontos mostra se o calor está se espalhando. Ver em Piscina →

🎯 Qual a diferença entre precisão, resolução e tempo de resposta?

Precisão = quão perto do valor real; resolução = menor variação que o sensor percebe (ex.: 0,0625 °C do DS18B20); tempo de resposta = quanto tempo leva para reagir a uma mudança. Comparativo visual em Sensores →

📈 Como os dados indicam se o sistema está aquecendo?

Lendo a temperatura ao longo do tempo: curva subindo = aquecendo; platô = alvo atingido (o relé desliga); descida lenta = perdas. O gráfico é a “assinatura” do funcionamento. Ver gráfico animado em Piscina →
